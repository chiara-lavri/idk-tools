Coordinate Navigator // text only

Enter latitude and longitude using the fields and nudge buttons below, or type a place name into the search box to find matching coordinates. There are no maps, no images, and no visual output of any kind — all results appear as plain text only, and the tool is screen reader accessible throughout. Geocoding is handled by Nominatim, OpenStreetMap's free reverse and forward geocoding service, which converts between coordinates and place names using OpenStreetMap's open geographic database. Reverse geocoding takes a latitude and longitude and returns the nearest named location; forward geocoding takes a place name and returns up to 50 matching results with their coordinates, which can be loaded directly into the fields.
